# Verify the Current Hackathon Constraints

Parent: [Chart the BLACKBOX Hackathon Project](../map.md)
Type: research
Status: resolved

## Question

What current first-party rules, judging criteria, sponsor requirements, submission artifacts, dates, and restrictions constrain BLACKBOX's Spec v0.1 and delivery strategy?

## Answer

BLACKBOX is eligible and strongly aligned if TrueForge performs substantive visible work: a real MCP tool call, generated code in the sandbox, and human approval before the policy mutation. The project may be developed in a private personal repository, but the submitted repository must be public, open source, reproducible, and delivered by **August 30, 2026 at 16:00 São Paulo time**. The final package needs the repository, reproducible README, an approximately three-minute working demo, and a short TrueForge explanation. Qodo should be connected before the first implementation PR and used throughout, despite inconsistent official wording about whether it is mandatory outside Best Code Quality.
